# Smart Event Room Management System

A Python-based Smart Event Room Management System that allocates rooms based on event priority using Data Structures and Algorithms.

## Features

- Priority-based Event Scheduling
- Max Heap Implementation
- Room Allocation
- Room Reuse
- Waiting List Management
- Object-Oriented Programming (OOP)

## Technologies Used

- Python
- Data Structures
- OOP

## Algorithms Used

- Max Heap
- Greedy Algorithm

## Project Structure

```
backend/
│── event.py
│── room.py
│── max_heap.py
│── min_heap.py
│── scheduler.py
└── main.py
```

## How to Run

```bash
cd backend
python3 main.py
```
